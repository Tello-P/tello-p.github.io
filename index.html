Embedded Qubit Engine

Q1.14 fixed-point quantum simulator in C · AVR / Arduino · WebAssembly debugger

A quantum state simulator written in plain C for microcontrollers. Every amplitude is a Q1.14 fixed-point complex number — two int16_t values — so a multi-qubit register fits in a few hundred bytes and runs on an 8-bit AVR with no FPU. Comes with a live trace debugger that runs the same C compiled to WebAssembly.
